## 3. 해결 방안 선택 (질문)
기성 청구 시 이 총괄표와 **1원 단위까지 완벽하게 일치**시키려면 어떤 방식을 선호하시나요?

**[1안] 단가 미세 조정 (추천)**
*   앱의 기초 단가(인건비/재료비)를 1~10원 단위로 미세하게 깎아서 총합을 강제로 맞추는 방식.
*   장점: 수식 일관성이 유지됨.

**[2안] 계약금액 화면 강제 고정**
*   수식 계산과 무관하게, 앱의 '계약 금액' 열에만 엑셀 원본의 하드코딩된 금액을 그대로 보여주도록 덮어씌우는 방식.
*   장점: 단가 수정 없이 화면만 원본과 동일하게 맞춤 (실제 기성 청구액에는 영향 없음).
