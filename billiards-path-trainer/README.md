# Carom Lab

3쿠션 당구의 공 배치와 예상 경로를 설계하고 샷 결과를 연습하는 브라우저 앱입니다.

## 실행

`당구_경로연습_실행.bat` 또는 `index.html`을 더블클릭합니다. 개발용 로컬 서버가 필요하면 아래 명령을 사용합니다.

```powershell
cd billiards-path-trainer
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 기능

- 수구·제1적구·제2적구 드래그 배치
- 각도, 세기, 상하·좌우 당점 조절
- 쿠션 반사와 적구 충돌 예상선
- 먼저 맞힐 적구를 선택한 뒤 3쿠션 성공 경로 자동 탐색
- 공 충돌, 감속, 쿠션 반발 애니메이션
- 두 적구 접촉과 3쿠션 충족 여부 판정
- 랜덤 배치와 배치 저장·불러오기
- 브라우저 로컬 저장소 기반 성공률 기록

이 버전은 훈련용 근사 물리 모델입니다. 실제 당구대의 천, 공, 쿠션 상태에 따라 결과가 달라질 수 있습니다.
