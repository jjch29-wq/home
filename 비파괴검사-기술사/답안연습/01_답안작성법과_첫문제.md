# 답안 작성법과 첫 문제

## 기술사 답안 기본 구조

### 1. 용어형

1. 정의
2. 핵심 원리 또는 공식
3. 주요 특징
4. 적용 분야
5. 한계 또는 주의사항

### 2. 서술형

1. 개요와 필요성
2. 원리 - 반드시 간단한 개념도 포함
3. 장비 구성 또는 시험 절차
4. 주요 변수와 결함 검출 특성
5. 장점과 단점
6. 적용 사례
7. 품질·안전·규격상 유의사항
8. 결론

## 첫 번째 연습문제

**문제:** 위상배열 초음파탐상검사(PAUT)의 원리와 특성을 설명하시오.

### 권장 목차

1. PAUT의 정의
2. 다중 압전소자와 시간지연 법칙
3. 전자주사 방식
   - 선형주사
   - 섹터주사
   - 동적 깊이집속
4. 장비 구성
5. 데이터 표시 방식
   - A-scan
   - S-scan
   - B/C-scan
6. 장점
7. 한계 및 오차요인
8. 용접부 검사 적용
9. 결론

### 반드시 들어갈 핵심어

- 다중 압전소자
- 시간지연(delay law)
- 빔 조향(steering)
- 집속(focusing)
- 섹터 스캔
- 검사 재현성
- 결함 위치·크기·방향
- 교정시험편

### 25분 작성 훈련

- 3분: 문제 요구사항 표시
- 5분: 목차 작성
- 15분: 본문과 그림 작성
- 2분: 누락·용어·단위 점검
