# 비파괴검사 기술사 학습실

이 폴더는 비파괴검사 기술사 시험을 위한 개인 학습 공간이다.

## 현재 기준 자료

- `기술사 2022-1.pdf` - PERFECT 2022 비파괴검사기술사(1)
- 이미지 스캔본 167쪽
- 초반 목차 기준 약 360개 이상의 문제와 해설 수록

## 학습 원칙

1. 검사법별 기본 원리를 먼저 이해한다.
2. 답안은 `정의 - 원리 - 장비/절차 - 영향인자 - 장단점 - 적용 - 기준` 순서로 구조화한다.
3. 매주 최소 3개 답안을 직접 작성한다.
4. 법령과 규격 수치는 반드시 최신판으로 별도 확인한다.
5. 틀린 내용은 오답노트에 기록하고 1일, 7일, 30일 간격으로 복습한다.

## 폴더 구성

- `학습계획` - 주간 계획과 진도표
- `문제분류` - 원문 문제의 분야별 분류
- `답안연습` - 직접 작성할 답안과 첨삭본
- `핵심이론` - 검사법과 재료·용접 핵심 정리
- `오답노트` - 혼동한 개념과 취약점

## 바로 시작하기

1. `desktop/비파괴검사_기술사_실행.bat`을 더블클릭하여 Windows 학습 UI를 연다.
2. `학습계획/12주_학습로드맵.md`를 읽는다.
3. `문제분류/2022-1_핵심문제.md`의 1주차 문제부터 공부한다.
4. `답안연습/01_답안작성법과_첫문제.md`에 첫 답안을 작성한다.

데스크톱 UI의 진도, 답안과 오답노트는 `desktop/study_data.json`에 자동 저장된다.

`주차별 학습답안` 메뉴에는 PERFECT 2022 (1)-(3)을 기준으로 정리한 12주, 48개 핵심 답안이 들어 있다. 법령·규격은 2022년 자료이므로 최신판과 대조해야 한다.

각 주차 화면은 `필수답안`과 `전체 관련문제` 탭으로 구성된다. 필수답안에는 대표 모범답안 4개가, 전체 관련문제에는 그 주차에 분류된 모든 문제가 핵심원리별 트리로 표시된다. 문제를 선택해 원문 해설을 열거나 답안연습으로 이동할 수 있다.

`문제은행`에는 교재 목차에서 복원한 전체 문제 370개가 들어 있다. 모든 문제에서 `원문 해설` 버튼으로 PDF의 해당 페이지를 바로 열 수 있다. 교재 원문에 없는 문제번호 66과 270-278은 색인에도 없다.

각 문제에는 학습주차, 핵심원리, 연관원리 태그, 답안유형(원리형·비교형·원인대책형·절차적용형·용어설명형), 난이도(기본·응용·심화)가 부여되어 있다. 문제은행의 `유사문제` 버튼을 누르면 같은 핵심원리 문제만 모아서 볼 수 있다.
