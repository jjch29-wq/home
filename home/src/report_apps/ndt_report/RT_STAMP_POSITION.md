# RT 보고서 직인 위치 기준

사용자 확인 기준: 2026-10-25 대화에 첨부한 RT 갑지·을지 스크린샷.

- 갑지와 을지 모두 상단 회사 정보 영역 오른쪽 끝, 보고서 제목 영역 바로 왼쪽에 배치한다.
- 회사 정보와 제목의 세로 경계선에 직인의 오른쪽 끝을 맞춘다. 제목 쪽으로 크게 넘어가지 않는다.
- 갑지: 대략 F~G열, 1~4행의 회사 정보 높이 안에 배치한다.
- 을지: 제목 시작 F열의 왼쪽 경계에 직인 오른쪽 끝을 맞춘다. 1~4행의 회사 정보 높이 안에 배치한다. 갑지와 열 너비 및 제목 시작 열이 다르므로 같은 셀 오프셋을 그대로 사용하지 않는다.
- 직인은 정사각형 비율과 투명 배경을 유지한다.
- 추가 을지에도 같은 상대 위치를 적용한다.

위 좌표는 스크린샷의 대략적인 범위다. 정확한 배치는 회사 정보/제목 경계와 머리글 높이를 기준으로 한다.
