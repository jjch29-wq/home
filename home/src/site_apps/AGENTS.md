# 사업장 격리 규칙

- `central`은 한국지역난방 중앙지사, `kogas`는 가스공사 가산~가평, `lotte`는 롯데건설 바이오로직스 전용이다.
- 사용자가 지목한 사업장 폴더만 수정한다. 다른 사업장에 같은 변경을 자동 복제하지 않는다.
- 각 사업장 내부의 `src` 모듈은 독립 복사본이다. 중복처럼 보이더라도 공통 모듈로 합치거나 원래 `home/src` 모듈을 다시 import하지 않는다.
- 로컬 import는 `site_apps.<사업장>.src...`를 사용한다. 다른 사업장 import, sys.modules 별칭으로 원본 모듈 재사용, 다른 사업장의 데이터 경로 사용을 금지한다.
- 설정, 재고, 이력, 사진, 양식은 해당 사업장 폴더 안의 파일을 사용한다. 사용자가 직접 선택한 외부 입출력 파일은 예외다.
- 원래 한글 파일명은 호환 실행기다. 업무 기능 수정은 해당 사업장 `src/app.py` 및 관련 모듈에서 한다.
- `home/archive/site_isolation_originals`는 복구용 원본이다. 기능 수정 대상이 아니다.
- 변경 후 `python home/tests/test_site_isolation.py`로 격리 경계를 확인하고, 해당 기능에 필요한 추가 검증을 한다.
