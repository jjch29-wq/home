# 속성정보 엑셀 생성

PMI 폴더의 `중앙지사_속성정보_생성.cmd`를 실행합니다. 기존 중앙지사 앱과 비파괴검사보고서 앱은 수정하지 않습니다.

## 폴더 자동 생성과 자동 연결

1. 중앙지사 이력을 불러오고 제출 폴더를 선택합니다.
2. **제출 폴더 틀 생성**을 누릅니다. 검사 기록별로 다음 구조를 만듭니다. 기존 파일은 덮어쓰거나 이동하지 않습니다.

```text
제출폴더/
  RT/라인번호/용접부번호/검사일자_최초(또는 보수)/
    보고서/보고서번호.pdf
    필름영상화/1-2.tif, 2-3.tif, 3-1.tif
  PAUT/라인번호/용접부번호/검사일자_검사구분/
    보고서/보고서번호.pdf
    데이터/
  MT/라인번호/용접부번호/검사일자_검사구분/보고서/
  PT/라인번호/용접부번호/검사일자_검사구분/보고서/
```

빈 폴더만 생성하며, 예시의 PDF·영상 파일은 사용자가 넣습니다. 검사구분이 원본에 없으면 `검사구분미확인`으로 표시하며 최초검사라고 추정하지 않습니다. 같은 경로가 되는 중복 기록은 `_기록-식별값`을 붙여 분리합니다. 중앙지사 원본에서 날짜·라인·용접부·검사구분이 변경되면 새 폴더 위치를 확인하세요.

3. 각 검사 폴더에 실제 파일을 넣은 뒤 **자료 자동 연결**을 누릅니다. 제출 폴더 선택 시에도 한 번 자동 연결을 실행합니다.
   - 보고서가 한 개이면 연결하고 파일명에서 보고서번호를 가져옵니다. 보고서번호가 이미 있으면 확장자를 제외한 파일명이 그 번호와 일치해야 합니다. 여러 후보면 자동 연결하지 않습니다.
   - RT는 해당 검사 폴더의 `필름영상화`에 직접 들어 있는 파일명에서 포인트를 읽습니다. `1-2.tif`, `2-3.jpg`처럼 사용합니다. 새 영상을 추가한 뒤 자동 연결을 다시 누르면 자동으로 연결했던 포인트 목록을 갱신합니다. 수동으로 지정한 연결은 유지합니다.
   - PAUT는 해당 검사 폴더의 `데이터` 안에 파일이 있으면 데이터 폴더를 연결합니다.
   - 여러 용접부가 같은 보고서를 공유하면 `RT/보고서`, `PAUT/보고서`, `MT/보고서`, `PT/보고서`에 보고서를 한 번만 둡니다. 각 기록의 보고서번호가 파일명과 일치하면 같은 보고서를 연결합니다. 번호가 없으면 보고서 데이터를 가져오거나 직접 번호를 입력하세요.
4. **엑셀 생성**으로 제출 폴더 최상위에 저장하고 실제 링크를 확인합니다.

## 개별 정보 확인과 수동 연결

1. RT, PAUT, MT, PT 폴더가 들어 있는 제출용 최상위 폴더를 선택합니다.
2. 실행하면 중앙지사 전용 동기화 설정의 `daily_work_history.json`을 자동으로 읽습니다. 다른 저장본을 사용하려면 위치를 선택하고 **중앙지사 이력 불러오기**를 누릅니다. 검사 목록은 중앙지사에 저장된 RT·PAUT·MT·PT 기록으로 고정됩니다.
3. 보고서 데이터로 부족한 정보를 보완할 때만 비파괴검사보고서 앱에서 **데이터 저장(JSON)** 한 파일을 준비합니다. 생성기에서 검사종류를 지정한 후 **보고서 데이터 추가**를 누릅니다. 일치하는 기록의 빈 정보만 보완하며, 중앙지사에 없는 검사 행은 추가하지 않습니다. 일치하지 않거나 중복인 보고서는 출력 엑셀의 **보고서 대조확인** 시트에 표시합니다. 표 형태의 미리보기 XLSX도 지원합니다. 서식이 병합된 완성 성적서 자체를 자동 판독하는 기능은 아닙니다.
4. **공통정보 입력**으로 공사명·시공사·하도사·용역사를 전체 기록의 빈 칸에 적용할 수 있습니다. 검사 기록을 두 번 클릭해 개별 값과 보고서 매수를 확인합니다. 원본의 `업체`를 시공사나 하도사로 임의 지정하지 않습니다. 같은 날짜·검사종류·라인번호·용접부번호·용접부특성의 유일한 기록만 병합합니다. 도면번호를 라인번호로 임의 대체하지 않습니다.
5. 각 기록에 해당 보고서를 연결합니다. RT는 필름영상화, PAUT는 데이터를 함께 연결합니다. 원본 데이터에 `보고서경로`, `필름영상화경로`, `데이터경로`가 있으면 가져옵니다. 링크는 제출 폴더 안의 자료만 허용합니다.
   - RT의 **필름영상화**에는 라인번호와 용접부번호가 경로 구성요소로 모두 포함된 전용 폴더를 선택합니다. 예: 라인 `LINE-01`, 용접부 `S01`이면 `RT/필름영상화/LINE-01/S01/`. 그 폴더에 직접 들어 있는 `1-2.tif`, `2-3.jpg`, `3-1.png` 등의 영상을 찾아 링크를 만듭니다. 하위 폴더는 검색하지 않습니다. 공유 RT 폴더나 소유 용접부를 확인할 수 없는 경로는 자동 검색을 차단합니다. 이 구조를 사용할 수 없거나 최초·재검사 영상이 섞여 있으면 **RT 포인트별 영상 연결**에서 해당 검사 영상 파일을 직접 지정하세요.
   - 파일명으로 포인트를 식별할 수 없으면 행 편집의 **RT 포인트별 영상 연결**을 누릅니다. `1-2` 등의 포인트를 입력하고 해당 영상 파일을 추가합니다. 같은 포인트의 여러 영상도 연결할 수 있습니다.
   - 원본 JSON에 `"RT영상": {"1-2": ["RT/필름영상화/S01/1-2.tif"], "2-3": ["RT/필름영상화/S01/2-3.tif"]}` 형식으로 연결정보를 넣어 가져올 수도 있습니다. 직접 지정한 연결이 폴더 자동 검색보다 우선합니다.
6. 편집·영상 연결 적용 시 제출 폴더의 `.central_attribute_connections.json`에 자동 저장합니다. 다음 실행 때 같은 제출 폴더를 선택하면 현재 중앙지사 기록에 일치하는 보완정보와 자료 연결을 자동 복원합니다. 파일을 이동할 때 이 파일도 함께 복사하면 생성기에서 연결을 재사용할 수 있습니다. **연결정보 저장/불러오기**는 별도 백업·복원용입니다. 예전 백업에만 있는 검사 기록은 다시 추가하지 않으며, 중앙지사 원본에 입력된 값은 백업 값으로 덮어쓰지 않습니다. 원본 날짜·라인·용접부 등 대조 키가 바뀌거나 중복되면 잘못된 자료 연결을 막기 위해 자동 복원에서 제외합니다.
7. **엑셀 생성**을 눌러 제출 폴더 최상위에 저장합니다. 기존 파일을 덮어쓰지 않습니다. 확인사항이 남으면 검토용 생성 여부를 안내합니다.

## 제출 폴더 예

```text
제출폴더/
  중앙지사_속성정보.xlsx
  RT/보고서/
  RT/필름영상화/
  PAUT/보고서/
  PAUT/데이터/
  MT/보고서/
  PT/보고서/
```

출력 엑셀의 첫 시트 `검사내역`에는 검사일자·종류·라인·용접부·검사결과·결함종류와 보고서, RT 포인트별 영상, PAUT 데이터 링크가 들어갑니다. `RT 1-2`, `RT 2-3`, `RT 3-1` 열의 링크를 클릭하면 해당 영상 파일을 직접 엽니다. 같은 포인트에 여러 파일이 있으면 `RT 1-2 (2)` 등으로 링크를 추가합니다. 영상은 기본 연결 프로그램에서 열리며 엑셀 파일 안에 포함되지 않습니다. TIFF와 DICOM은 해당 형식을 지원하는 뷰어가 필요합니다.

보고서는 **보고서번호 자체를 클릭**해 엽니다. 원본 데이터의 `보고서번호`, `Report No.` 등을 가져오며 행 순번 `No`를 보고서번호로 사용하지 않습니다. 번호가 없으면 행 편집에서 입력하세요. 번호만 있고 원본 파일을 연결하지 않으면 번호는 표시되지만 링크는 생성되지 않습니다.

중앙지사에서 이미 입력한 값은 행 편집에서 읽기 전용이며, 수정이 필요하면 중앙지사 앱에서 고친 후 다시 불러옵니다. 비어 있는 값만 생성기에서 보완합니다. RT `구간정보`가 `1-2,2-3,3-1` 같은 명확한 포인트 목록이면 이를 이용해 `2/3 포인트 연결`과 빠진 포인트의 `미연결`을 표시합니다. 전체 포인트 목록이 없으면 `전체 포인트 미확인`으로 표시합니다. 검사차수는 원본에 `검사차수` 또는 `재검사차수`가 있을 때만 표시하며, 핫태핑 차수를 검사차수로 대체하지 않습니다.

동일한 대조 키의 중복 기록, 삭제된 기록, 대조 키가 바뀐 기록의 기존 보완정보는 자동 저장 파일의 `unresolved` 목록에 보존합니다. 원래 검사 행에 임의로 연결하지 않습니다. 보류 건수는 화면에 표시하고, 엑셀 생성 시 `연결 복원보류` 시트에 보고서번호와 기존 경로를 기록합니다. 해당 자료를 확인한 뒤 현재 검사 기록에 직접 연결하세요. 중앙지사/보고서 불일치 등의 저장된 경고는 재실행 후에도 유지합니다. RT_OR·RT_RE는 0보다 큰 수량만 최초·보수 검사 구분에 사용합니다.

`속성정보` 시트에는 제출용 세부 속성과 포인트별 링크, `제출파일목록`에는 검사 폴더 내 전체 파일의 링크가 들어갑니다. 폴더를 통째로 메모리카드에 복사하고 파일명·내부 폴더 구조를 유지합니다. 상대경로를 사용하므로 드라이브 문자가 달라져도 같은 구조의 파일을 가리킵니다. 실제 열기는 Excel의 보안 설정과 연결 프로그램 영향을 받으므로 제출용 PC에서 확인합니다. RT 영상 수는 연결된 경로 수이며, 촬영 완료 여부는 보고서의 실제 포인트 목록과 대조해야 합니다.

결함종류 공란은 무결함으로 간주하지 않습니다. RT D1~D15 표식을 결함코드로 임의 변환하지 않습니다. 과업내용서 원본의 항목 누락, 결함코드 기준, 무결함 표기 방식은 별도로 확인해야 합니다. 확인사항은 생성 시점의 정적 결과이며, 엑셀을 직접 편집해도 재계산되지 않습니다.
