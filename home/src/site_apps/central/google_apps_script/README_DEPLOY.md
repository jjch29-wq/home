# 한국지역난방공사 중앙지사 24시간 모바일 클라우드 시스템 배포 가이드

본 가이드는 **사무실 PC가 꺼져 있어도 스마트폰에서 24시간 365일 언제든 작업일보를 저장**할 수 있는 100% 무료 구글 클라우드(Google Apps Script + Google Sheets) 배포 방법입니다.

---

## 📌 주요 특징
1. **100% 평생 무료**: 구글 드라이브 기본 제공 기능으로 서버비나 호스팅 비용이 전혀 없습니다.
2. **PC 무관 24시간 작동**: 사무실 컴퓨터를 끄고 퇴근하거나 주말/공휴일에도 스마트폰에서 즉시 접속 및 저장됩니다.
3. **사무실 엑셀 자동 동기화**: PC를 켰을 때 `sync_google_sheet.py` 또는 중앙지사 PC 프로그램 실행 시 구글 시트에 쌓인 내역이 로컬 `Material_Inventory.xlsx`의 `DailyUsage`로 한 번에 자동 동기화됩니다.
4. **한국지역난방공사 중앙지사 규격 완전 일치**:
   - PAUT, RT, MT, PT 단가계약 자동 계산
   - 공사구분: 열수송관, 플랜트(관리소), 열배관, 핫태핑 (1차/2차 차수 및 개소 지원)
   - RTK 결함 8종 및 NDT 소모 약품 7종 기입 지원
   - 중앙지사 전용 11명 작업자 및 15대 차량 마스터 연동

---

## 🚀 배포 방법 (소요 시간: 약 3분)

### 1단계: 구글 드라이브에서 스프레드시트 생성
1. 인터넷 브라우저(크롬 등)에서 [Google Drive](https://drive.google.com/) 접속 및 로그인
2. 좌측 상단 **[+ 새로 만들기]** → **[Google 스프레드시트]** 클릭
3. 시트 제목을 `중앙지사_모바일_일보_클라우드`로 변경

---

### 2단계: Apps Script 편집기 열기
1. 상단 메뉴에서 **[확장 프로그램]** → **[Apps Script]** 클릭
2. 프로젝트 이름을 `중앙지사_모바일_서버`로 변경

---

### 3단계: 소스 코드 복사 & 붙여넣기

#### ① Code.gs 붙여넣기
1. 좌측 파일 목록의 `Code.gs` 클릭 (기존 내용 모두 삭제)
2. `home/src/site_apps/central/google_apps_script/Code.gs`의 전체 내용을 복사하여 붙여넣고 저장(`Ctrl + S`)

#### ② index.html 생성 및 붙여넣기
1. 좌측 파일 목록의 **[+]** 아이콘 클릭 → **[HTML]** 선택
2. 파일 이름을 **`index`** 로 입력 (확장자 `.html`은 자동 부여됨)
3. `home/src/site_apps/central/google_apps_script/index.html`의 전체 내용을 복사하여 붙여넣고 저장(`Ctrl + S`)

---

### 4단계: 웹 앱으로 배포 (스마트폰 접속 주소 생성)
1. 우측 상단 파란색 **[배포]** 버튼 클릭 → **[새 배포]** 선택
2. 왼쪽 톱니바퀴 아이콘 클릭 → **[웹 앱(Web App)]** 선택
3. 다음 옵션을 정확히 설정합니다:
   - **설명**: `중앙지사 모바일 현장 입력 v1.0`
   - **다음 사용자로 실행**: `나 (내 Google 계정)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자 (Anyone)`**  *(중요: 현장 작업자 누구나 접속하기 위함)*
4. 하단 **[배포]** 클릭
5. 최초 1회 "액세스 승인" 창이 뜨면:
   - **[액세스 승인]** 클릭 → 본인 구글 계정 선택
   - 경고창에서 좌측 하단 **[고급]** 클릭 → 하단 **[중앙지사_모바일_서버(으)로 이동(안전하지 않음)]** 클릭
   - **[허용]** 클릭
6. 화면에 생성된 **웹 앱 URL** (예: `https://script.google.com/macros/s/.../exec`)을 복사합니다.

---

### 5단계: 스마트폰 홈 화면에 추가
1. 복사한 웹 앱 URL을 카카오톡이나 문자로 본인 스마트폰에 전송
2. 스마트폰 브라우저에서 링크 열기
3. 브라우저 메뉴에서:
   - **갤럭시(삼성인터넷/크롬)**: 우측 메뉴 `⋮` → **[홈 화면에 추가]**
   - **아이폰(사파리)**: 하단 공유 아이콘 `⎋` → **[홈 화면에 추가]**
4. 스마트폰 바탕화면에 "중앙지사 24시간 현장입력" 앱 아이콘이 생성되어 24시간 언제든 사용할 수 있습니다!

---

## 🔄 PC 프로그램과 구글 클라우드 자동 동기화

1. `home/src/site_apps/central/data/google_sync_config.json`에 4단계에서 생성된 웹 앱 URL을 입력합니다:
```json
{
  "web_app_url": "https://script.google.com/macros/s/배포키/exec"
}
```
2. 중앙지사 PC 프로그램을 실행(`중앙지사_실행.bat`)하면, 시작 즉시 구글 클라우드 내역을 자동 취합하여 화면에 로드합니다.
