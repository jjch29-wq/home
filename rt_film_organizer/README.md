# RT 필름 영상화 정리기

고정된 카메라로 촬영한 RT 필름 사진을 동일 좌표로 일괄 자르고, 납마킹을 OCR로 읽어 파일명을 만드는 Windows용 로컬 앱입니다.

## 안전 원칙

- 원본 사진은 변경하거나 삭제하지 않습니다.
- 결과는 사용자가 지정한 별도 폴더에 JPG로 저장합니다.
- 대비, 선명도, 합성 처리를 하지 않습니다. 크롭만 수행합니다.
- OCR 결과는 오인식 가능성이 있으므로 표에서 반드시 확인한 뒤 저장합니다.
- 처리 결과와 OCR 원문은 `영상화_작업기록.csv`에 기록됩니다.
- 크롭 결과가 과업 최소 해상도 `2,048×1,536`보다 작으면 저장 전에 경고합니다. 앱은 부족한 이미지를 인위적으로 확대하지 않습니다.

## 실행

### VS Code에서 Run / Debug

1. `desktop_app.py`를 엽니다.
2. 실행 및 디버그 화면에서 `RT 필름 영상화 정리기 (Run/Debug)` 구성을 선택합니다.
3. `F5`는 디버그 실행, `Ctrl+F5`는 디버깅 없이 실행입니다.

간단히 실행하려면 `run_app.bat`을 더블클릭해도 됩니다. 앱은 소스 코드에서 직접 실행되므로 `desktop_app.py`와 `core.py`를 수정한 내용이 다음 실행부터 바로 반영됩니다. 사진과 OCR 정보는 외부로 전송하지 않습니다.

1. 입력 폴더와 출력 폴더를 선택합니다.
2. `사진 불러오기`를 누릅니다.
3. `필름영역 검출`로 자동 영역을 잡거나, `영역 직접 지정`을 누른 뒤 미리보기에서 마우스로 자를 영역을 드래그합니다.
4. OCR과 파일명 변경 없이 자르기만 하려면 `일괄 자르기`를 누릅니다. 결과는 출력 폴더 아래 `일괄자르기` 폴더에 원본 이름으로 저장됩니다.
5. 자동 파일명까지 만들려면 `OCR 일괄 분석`을 누릅니다.
6. 라인번호, JOINT, 용접사, 구간을 더블클릭하여 확인·수정합니다.
7. 파일명 규칙을 선택하고 `OCR명으로 저장`을 누릅니다.

사진은 파일명 순서대로 3장씩 묶어 `(1-2)`, `(2-3)`, `(3-1)`을 기본 구간으로 확정합니다. `JY/JA2026` 위쪽과 `100A` 위쪽의 작은 납숫자 OCR 결과는 촬영 순서와 일치하는지 검증하는 용도로 사용합니다.

불량 보수 촬영 JOINT는 `R06R`, `S01R`처럼 끝에 `R`이 붙은 형식을 지원합니다. OCR이 `RO6R`처럼 숫자 0을 문자 O로 읽어도 `R06R`로 정규화합니다.

원촬영 `R06`은 3장 순서로 구간을 배정하지만, 보수 재촬영 `R06R`은 1장 또는 2장만 추가될 수 있습니다. 보수 사진의 구간은 촬영목록 위치로 추정하지 않고 납마킹 OCR을 사용하며, 인식하지 못하면 `확인필요(보수구간 선택)`로 표시하여 드롭다운 선택을 요구합니다.

`구간판정` 열의 의미는 다음과 같습니다.

- `촬영순서/OCR일치`: 촬영 순서와 납마킹 OCR 값이 일치
- `촬영순서`: OCR은 실패했지만 정해진 촬영 순서로 배정
- `확인필요(OCR불일치)`: 촬영 순서와 납마킹 OCR 값이 달라 확인 필요
- `수동확인`: 사용자가 구간 셀을 직접 수정한 값

구간 셀은 드롭다운으로 제공되며 빈 값, `(1-2)`, `(2-3)`, `(3-1)` 중에서 선택할 수 있습니다. 선택한 값은 즉시 파일명과 작업기록에 반영됩니다.

기본 파일명은 과업내용서 예시에 맞춘 `{joint}-{seq}.JPG`입니다. 다른 항목을 포함하려면 콤보박스에서 규칙을 선택하거나 직접 입력할 수 있습니다.

## 참고

EasyOCR 모델은 최초 OCR 실행 때 한 번 내려받을 수 있습니다. 인터넷이 차단된 PC라면 모델 폴더를 별도로 배포해야 합니다.
